# Comparing Computational Models and Intertemporal Choice Data in a Shared Latent Space

Code accompanying the paper presented at the NeurIPS 2026 Sim2Science Workshop.

This repository contains the intertemporal-choice simulators, experimental designs, latent representation models, geometric support analyses, and selected robustness checks.

The original development repository is preserved separately. Raw third-party behavioral datasets and generated training outputs are not included.

## Components

- `src/`: Simulator definitions, trial generation, Neural Process and alternative representations.
- `experiments/`: Trial generation, simulation, representation training, support analyses, and paper figures.
- `camera_ready/`: Selected supplementary and robustness analyses.
- `tests/`: Selected model and data-interface tests.

## Data

Published experimental designs and behavioral datasets are described in the paper. Obtain any third-party datasets from their original providers and respect their licenses.
